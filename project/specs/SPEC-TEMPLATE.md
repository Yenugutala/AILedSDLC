# Spec Template — Securities Master Data Lakehouse

Use this template as a reference when creating new use-case specs.
All YAML spec files are auto-generated by the BA Agent and refined by the Architect Agent.

## Bronze Layer (`statestreet.b_statestreet.<table>`)

```yaml
# tables.yaml
tables:
  - name: <table>                       # keep original CSV file name
    catalog: statestreet
    schema: b_statestreet
    source_file: <file>.csv
    partition_by: [_ingestion_ts]
    tblproperties:
      delta.universalFormat.enabledFormats: iceberg
    columns:
      - name: <col>
        type: STRING
      # ... data columns ...
      - name: _ingestion_ts
        type: TIMESTAMP
      - name: _source_file
        type: STRING
      - name: _batch_id
        type: STRING
      - name: _row_hash
        type: STRING

# rules.yaml
rules:
  - table: <table>
    checks:
      - id: not_null_<key_col>
        sql: SELECT COUNT(*) FROM statestreet.b_statestreet.<table> WHERE <key_col> IS NULL
        expect: 0
```

## Silver Layer (`statestreet.s_statestreet.<table>`)

```yaml
# tables.yaml  (adds SCD2 columns)
tables:
  - name: <table>
    catalog: statestreet
    schema: s_statestreet
    scd2: true
    primary_key: [<key_col>]
    columns:
      # ... all bronze columns ...
      - name: effective_start_date
        type: DATE
      - name: effective_end_date
        type: DATE
      - name: is_current
        type: BOOLEAN
      - name: _dq_rule_version
        type: STRING

# rules.yaml
rules:
  - table: <table>
    checks:
      - id: valid_<col>
        sql: SELECT COUNT(*) FROM statestreet.s_statestreet.<table> WHERE <condition>
        expect: 0
```

## Gold Layer (`statestreet.g_statestreet.dim_<name>` / `fact_<name>`)

```yaml
# tables.yaml
tables:
  - name: dim_<name>                    # or fact_<name>
    catalog: statestreet
    schema: g_statestreet
    grain: [<key_col>]
    tblproperties:
      delta.universalFormat.enabledFormats: iceberg
    columns:
      - name: <key_col>
        type: STRING
        comment: "Primary key — <description>"
      # ... remaining columns with comments for Genie ...

# rules.yaml
rules:
  - table: dim_<name>
    checks:
      - id: no_null_key
        sql: SELECT COUNT(*) FROM statestreet.g_statestreet.dim_<name> WHERE <key_col> IS NULL
        expect: 0
      - id: row_count
        sql: SELECT COUNT(*) FROM statestreet.g_statestreet.dim_<name>
        expect_gt: 0
```
