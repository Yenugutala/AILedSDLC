## CLI Commands

### `sml index`

| | Detail |
|---|---|
| **Purpose** | Index the full codebase, skills, and specs into ChromaDB for agent retrieval |
| **Run when** | Once before demo; re-run when notebooks, specs, or skills files change |
| **Input** | Repo file system (no credentials needed) |
| **Output** | ChromaDB collection `ai-dlc` at `.chroma/` |

**What gets indexed:**

| Source Pattern | Type Tag | Examples |
|---|---|---|
| `project/use-cases/**/*.yaml` | `spec` | bronze/tables.yaml, gold/tables.yaml |
| `project/use-cases/**/*.md` | `doc` | known_issues.md |
| `project/notebooks/*.py` | `code` | 03_bronze_ingest.py |
| `project/notebooks/*.sql` | `code` | 05_gold_build.sql |
| `project/tests/*.py` | `test` | test_gold.py |
| `project/docs/*.md` | `doc` | lineage.md, hld.md |
| `project/specs/*.md` | `doc` | SPEC-TEMPLATE.md |
| `project/skills/*.md` | `knowledge` | data_dictionary.md, ontology.md |
| `project/skills/**/*.md` | `knowledge` | All subdirectory skill files |
| `project/use-cases/**/join_map.yaml` | `join_map` | Auto-generated by `sml profile` |
| `CLAUDE.md` | `standards` | Naming + coding standards |
| Jira ticket text | `jira` | Indexed automatically in Beat 1 |

**Chunk settings:** 800 chars max per chunk, 20% overlap
**Embedding model:** `sentence-transformers/all-MiniLM-L6-v2`

### `sml schema`

| | Detail |
|---|---|
| **Purpose** | Index live Databricks column names and types into ChromaDB (schema-only, no data profiling) |
| **Run when** | After `sml index`; use as fallback when `sml profile` is not feasible |
| **Input** | `DATABRICKS_HOST`, `DATABRICKS_TOKEN`, `DATABRICKS_WAREHOUSE_ID` from `.env` |
| **Output** | ChromaDB collection `schema_catalog` at `.chroma/` |
| **SQL run** | `SELECT * FROM statestreet.information_schema.columns WHERE table_schema IN (b_,s_,g_statestreet)` |

**Per document stored:**

| Field | Source |
|---|---|
| `table` | `table_catalog.table_schema.table_name` |
| `column` | `column_name` |
| `layer` | Derived: `b_` → bronze, `s_` → silver, `g_` → gold |
| `data_type` | `data_type` from INFORMATION_SCHEMA |
| `nullable` | `is_nullable` |
| `comment` | `comment` (from COMMENT ON COLUMN, if set) |

**Limitation:** No data values, no profiling, no join detection. Use `sml profile` for richer context.

### `sml profile`

| | Detail |
|---|---|
| **Purpose** | Profile every column from actual data → generate AI descriptions → detect joins → build join map |
| **Run when** | Before demo (preferred over `sml schema`); re-run after schema changes or data loads |
| **Input** | `DATABRICKS_HOST`, `DATABRICKS_TOKEN`, `DATABRICKS_WAREHOUSE_ID` |
| **Output** | ChromaDB collection `data_catalog` + `project/use-cases/securities-master/join_map.yaml` |
| **Model used** | Claude Haiku (fast + cheap for batch description generation) |

**Per column — profiling SQL run:**

```sql
-- Null % and cardinality (all column types)
SELECT
  ROUND(100.0 * SUM(CASE WHEN col IS NULL THEN 1 ELSE 0 END) / COUNT(*), 1) AS null_pct,
  COUNT(DISTINCT col) AS cardinality
FROM table

-- Numeric columns: MIN/MAX
SELECT MIN(col), MAX(col) FROM table WHERE col IS NOT NULL

-- String/enum columns: top-5 values by frequency
SELECT CAST(col AS STRING) AS val, COUNT(*) AS cnt
FROM table WHERE col IS NOT NULL
GROUP BY col ORDER BY cnt DESC LIMIT 5
```

**Per document stored in `data_catalog`:**

| Field | Source |
|---|---|
| `table_fqn` | Full 3-part table name |
| `column` | Column name |
| `layer` | bronze / silver / gold |
| `data_type` | INFORMATION_SCHEMA |
| `null_pct` | Profiling SQL |
| `cardinality` | Profiling SQL |
| `sample_values` | Top-5 values or MIN/MAX |
| `description` | **Claude Haiku generated** from column name + data profile |
| `is_join_key` | `True` if column appears in 2+ tables |
| `join_tables` | List of all tables containing this column |

**join_map.yaml output structure:**
```yaml
join_keys:
  product_id:
    tables: [statestreet.b_statestreet.product, statestreet.s_statestreet.product, ...]
    appears_in_n_tables: 12
    likely_role: primary/foreign key
  scale_id:
    tables: [statestreet.s_statestreet.tick, statestreet.s_statestreet.tick_ladder_scale]
    appears_in_n_tables: 2
    likely_role: primary/foreign key

relationships:
  - from_table: statestreet.s_statestreet.product
    to_table: statestreet.s_statestreet.bond
    join_key: product_id
    cardinality: 1:0..1
```

### Beat 4 — Developer + QA Agents

#### Developer Agent

| | |
|---|---|
| **Model** | Claude Sonnet 4.6 |
| **Input** | `gold/tables.yaml` (with net_settlement_amount), ticket context |
| **ChromaDB query** | "gold build SQL notebook settlement amount bond muni" → top-10 from `ai-dlc` |
| **Top retrieved** | `data_engineering.md`, `known_issues.md`, `05_gold_build.sql` (existing), `ontology.md` |

**Output:** Updated `project/notebooks/05_gold_build.sql`
```sql
CREATE OR REPLACE TABLE statestreet.g_statestreet.securities_master
USING DELTA
TBLPROPERTIES ('delta.universalFormat.enabledFormats' = 'iceberg')
AS
SELECT
  ...,
  CASE
    WHEN product_type IN ('bond','muni') AND principal_amount IS NOT NULL
    THEN principal_amount * (CAST(1 AS DECIMAL(18,6)) + accrued_interest_rate)
    ELSE NULL
  END AS net_settlement_amount
FROM silver_product sp
LEFT JOIN silver_bond sb ON sp.product_id = sb.product_id
LEFT JOIN silver_debt sd ON sp.product_id = sd.product_id
WHERE sp.is_current = TRUE;

COMMENT ON COLUMN statestreet.g_statestreet.securities_master.net_settlement_amount IS
  'REQ-01: Net cash amount due at settlement. Derived: principal_amount × (1 + accrued_interest_rate). Bond/muni only.';
```

#### QA Agent

| | |
|---|---|
| **Model** | Claude Sonnet 4.6 |
| **Input** | Generated SQL + ticket REQs |
| **ChromaDB query** | "pytest databricks gold table settlement amount test" → top-10 from `ai-dlc` |
| **Top retrieved** | `testing_patterns.md`, `dq_patterns.md` |

**Output:** `project/tests/test_gold.py`
```python
def test_net_settlement_null_for_non_bond():
    # REQ-03: Only bond/muni rows should have non-null values
    result = spark.sql("""
        SELECT COUNT(*) AS bad_rows
        FROM statestreet.g_statestreet.securities_master
        WHERE product_type NOT IN ('bond','muni')
          AND net_settlement_amount IS NOT NULL
    """).collect()[0]["bad_rows"]
    assert result == 0, f"Found {result} non-bond/muni rows with net_settlement_amount populated"

def test_is_current_only():
    # REQ-04: Gold grain — current rows only
    result = spark.sql("SELECT COUNT(*) FROM ... WHERE is_current != TRUE").collect()[0][0]
    assert result == 0
```

## Error Reference

| Error | Cause | Fix |
|---|---|---|
| `Schema catalog not indexed` warning | `sml schema` not run | Run `sml schema` or `sml profile` |
| `Data catalog not indexed` warning | `sml profile` not run | Run `sml profile` (recommended) |
| `DATABRICKS_WAREHOUSE_ID not set` | Missing in `.env` | Add warehouse ID to `.env` |
| Beat 3 Check 3 re-check fails | Claude returned 0 columns | Check ticket requirements are clear; run `sml index` to refresh codebase |
| `gh pr create failed` | `gh` CLI not authenticated | Run `gh auth login` |
| `databricks bundle run` error | Bundle not deployed | Run `sml deploy` first |
| `NoneType has no attribute get` on priority | Jira field is null | Fixed — uses `(f.get("priority") or {}).get(...)` |
| `SyntaxError: from __future__ imports` | Duplicate import | Fixed — only one `from __future__ import annotations` per file |
